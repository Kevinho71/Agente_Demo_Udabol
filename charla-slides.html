Un bucle de código que usa un modelo que devuelve texto.

Texto entra. Texto sale.

Un modelo de lenguaje (LLM) es una función probabilística: recibe texto y devuelve texto. Nada más.

entra: ¿Cuál es la capital de Bolivia?

SucreeslacapitalconstitucionaldeBolivia.

Predice el siguiente token, una y otra vez.

Cada llamada empieza de cero.

El modelo no conserva el turno anterior. No hay una sesión viviendo en el servidor.

Llamada 1

usuario Me llamo Kevin. modelo Mucho gusto, Kevin.

Llamada 2

usuario ¿Cómo me llamo? modelo No tengo esa información.

La memoria es una ilusión útil.

Recuerda porque tu app reenvía todo el historial en cada llamada.

messages: [ { role: "user", text: "Hola" }, { role: "assistant", text: "¿Qué necesitas?" }, { role: "user", text: "Consulta mi catálogo" } ]

El modelo recibe todo, en cada llamada.

Un agente es un bucle.

Tu código rodea al modelo y decide cuándo parar.

El modelo solo pide. No ejecuta.

La seguridad vive en tu backend, no en el prompt.

Le describes tus herramientas.

Cada función es un contrato: nombre, propósito y parámetros.

{ "name": "list_products", "description": "Consulta el catálogo", "parameters": { "sort_by": "price", "order": "desc", "limit": 1 } }

El modelo no ve tu función. Ve esta descripción.

El modelo propone, tu código ejecuta.
